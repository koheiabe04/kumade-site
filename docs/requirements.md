## 1. プロジェクト概要

### 1.1 事業内容
**くまで** は PR・ブランディング会社。
- 制作：Webサイト／バナー／名刺 など、クリエイティブ制作からスタート
- 伴走支援：事業の伴走（継続的なブランディング・PR支援）

### 1.2 サイトの目的
- 種類：**ブランドサイト**
- 主目的：**集客**（問い合わせ獲得）。会社の世界観・実績を伝え、相談につなげる。

### 1.3 ゴール・KPI
- 主要CV：**問い合わせフォーム送信**
- 数値目標：【要決定】（例：月間問い合わせ◯件）。運用開始後に設定でも可。

## 4. 機能要件

### 4.1 必須機能（確定）
- **問い合わせフォーム**：入力 → バリデーション → 送信 → 完了。送信先＝**メール通知（Formspree）**。スパム対策（honeypot等）込み。
- **実績紹介ページ**：事例カード一覧 → 詳細（概要・課題・制作物・成果）。
- レスポンシブ表示、グローバルナビ＋モバイルメニュー、OGP、SEO基本対応。

### 4.2 補足
- 立ち上げ期のため実績は当初少数の想定。**0件でも崩れないUI**（「準備中」表示やサンプル）を用意。
- 実績データはリポジトリ内で管理（MDX or データファイル）。CMSは不要。
- SNS：**note または Instagram**（開始予定）。決まり次第ヘッダー／フッターにリンク追加。

## 6. デザイン要件 / ブランドガイドライン

### 6.1 ブランドストーリー（サイトの背骨）
- 社名 **くまで** ＝ **熊手**（福をかき集める縁起物・かき寄せる道具）＋ **福島県大熊町からの出発**。
- コピー：**「かき集めろ、地方から。」**
- ロゴ解釈：白い形＝**熊手の爪**、右上のオレンジの丸＝**昇る朝日（＝出発・希望）**。
  - ※この解釈で世界観・コピー・イラストの方向性を統一。意図と違えば調整。
- 訴求の軸：地方発の熱量／一社一社の「福」を集めて伴走する姿勢／前向きさ。

### 6.2 カラーパレット（ロゴ実測）
| 役割 | HEX | 用途 |
|---|---|---|
| Primary（赤） | `#E93119` | 主要ボタン / 強調 / ロゴ地色 |
| Primary Dark | `#C4280F` | ボタンhover / 押下 |
| Accent（朝日イエロー） | `#F9B923` | アクセント / バッジ / ハイライト |
| Ink（文字） | `#1A1A1A` | 本文 |
| Muted | `#6B6B6B` | 補足・キャプション |
| Surface | `#FFFFFF` | 基本背景 |
| Surface Tint | `#FFF6F4` | セクション区切りの淡い背景 |

→ Tailwind の `theme.extend.colors` にトークンとして登録（例：`brand`, `brand-dark`, `accent`）。

### 6.3 デザイン方針（写真素材なしを前提）
- 写真が無いため、**グラフィック・タイポグラフィ・カラー・余白・モーションで魅せる**設計。
- 熊手の爪／朝日のモチーフを、装飾・区切り・アイコンに展開（ロゴSVGのパーツ流用）。
- 角丸・力強い大見出し・広めの余白で、ロゴの印象（元気・前向き・親しみ）に合わせる。
- 制作会社のサイト自体が「実績」になるため、クオリティ優先。

### 6.4 タイポグラフィ
- 和文：Noto Sans JP（見出しBold／本文Regular）
- 欧文・数字：Inter または Poppins
- 見出しは太く大きく、行間ゆったり。

### 6.5 ロゴ
- **PNG → SVG化する（確定）**。favicon・OGP・各種サイズに展開。
- 最小サイズ幅32px以上、周囲にロゴ高さ1/4以上の余白。

## 7. 技術要件

### 7.1 スタック（確定）
- **Next.js (App Router) + Tailwind CSS**。ブログ・CMS・DBなし → 静的中心の軽量構成。
- ホスティング **Vercel**：GitHub連携で main push を自動デプロイ、PRごとにプレビュー生成。
- アイコン：lucide 等の軽量セット。

### 7.2 ドメイン
- **これから取得**。【要決定】希望文字列（例：`kumade.jp` / `kumade.co.jp` 等）。取得後 Vercel でDNS設定。

### 7.3 フォーム送信（確定）
- **Formspree** を利用。フォーム送信 → 指定アドレスへメール通知。
- 【要決定】通知先メールアドレス。

### 7.4 リポジトリ構成（案）
```
/
├─ CLAUDE.md            # Claude Code向け開発ルール（カラー/フォント/規約）
├─ docs/requirements.md # 本書

├─ src/
│  ├─ app/              # App Router（各ページ）
│  ├─ components/

```
